# ملاحظاتي

تطبيق ملاحظات عربي احترافي بواجهة RTL كاملة، يعمل بالكامل داخل المتصفح دون خادم أو قاعدة بيانات خارجية. لكل مستخدم حساب مستقل ببريد إلكتروني وكلمة مرور، وملاحظات معزولة تمامًا عن بقية الحسابات.

**الموقع المباشر:** https://abdulfatailabeeb93-cmd.github.io/notes-app/

## التشغيل

يكفي فتح `index.html` في متصفح حديث، أو تشغيل خادم محلي بسيط (مُفضَّل):

```powershell
cd notes-app
python -m http.server 8765
```

ثم زيارة `http://localhost:8765/`.

> يُنصح باستخدام خادم محلي لأن بعض المتصفحات تقيّد ميزات التشفير (`crypto.subtle`) عند الفتح المباشر عبر `file://`. يتضمن التطبيق بديلًا احتياطيًا، لكن الخادم المحلي يضمن أفضل توافق.

## المزايا

- تسجيل حساب جديد وتسجيل دخول ببريد إلكتروني وكلمة مرور.
- عزل كامل للبيانات: كل حساب يرى ملاحظاته فقط.
- إنشاء وتعديل وحذف الملاحظات، مع سلة محذوفات واستعادة وحذف نهائي.
- تثبيت الملاحظات وإضافتها إلى المفضلة.
- بحث فوري، وترتيب حسب آخر تعديل أو تاريخ الإنشاء أو العنوان.
- عرض شبكي أو قائمة.
- ألوان للملاحظات، وعدّاد كلمات، وتنبيه قبل إغلاق المحرر مع تغييرات غير محفوظة.
- مظهر فاتح/داكن/حسب النظام، وتصميم متجاوب للجوال.
- إعدادات الحساب: تحديث الاسم، تغيير كلمة المرور، تصدير الملاحظات بصيغة JSON، حذف كل الملاحظات، وحذف الحساب.
- اختصارات لوحة المفاتيح (بحث سريع، ملاحظة جديدة، حفظ، إغلاق).

## تخزين البيانات

تُحفظ البيانات في `localStorage` تحت المفاتيح التالية:

| المفتاح | المحتوى |
| --- | --- |
| `mulahazati.users.v1` | قائمة الحسابات (البريد، الاسم، ملح التشفير، وبصمة كلمة المرور) |
| `mulahazati.notes.v1.<userId>` | ملاحظات كل مستخدم على حدة |
| `mulahazati.session.v1` | الجلسة الحالية (في `localStorage` عند تفعيل «تذكرني»، أو في `sessionStorage` عند عدم تفعيله) |
| `mulahazati.theme.v1` | تفضيل المظهر |
| `mulahazati.layout.v1` | تفضيل طريقة العرض |

كلمات المرور لا تُحفظ كنص صريح؛ تُشتق بصمة `PBKDF2-SHA256` (120,000 دورة) مع ملح عشوائي لكل حساب.

## ملاحظات الخصوصية والأمان

- هذا تطبيق محلي بالكامل: لا يتم إرسال أي بيانات إلى أي خادم.
- الملاحظات نفسها **غير مشفّرة** داخل `localStorage`؛ أي شخص يملك وصولًا إلى المتصفح أو ملفات الجهاز يمكنه قراءتها. الحماية هنا هي عزل الحسابات داخل التطبيق، وليست تشفيرًا للقرص.
- مسح بيانات المتصفح أو استخدام وضع التصفح الخاص قد يؤدي إلى فقدان الحسابات والملاحظات نهائيًا.
- لا توجد مزامنة بين الأجهزة، ولا استعادة لكلمة المرور عبر البريد (لأنه لا يوجد خادم بريد).
- للاستخدام الحقيقي متعدد الأجهزة، يلزم نقل التخزين إلى خادم آمن مع تشفير النقل والتخزين ومصادقة قوية.

## الملفات

- `index.html` — بنية الواجهة العربية و RTL.
- `styles.css` — نظام التصميم، المظهران الفاتح والداكن، والتجاوب.
- `app.js` — المصادقة، الجلسات، إدارة الملاحظات، الإعدادات، والتفاعلات.
