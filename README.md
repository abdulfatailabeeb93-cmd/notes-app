# ملاحظاتي

تطبيق ملاحظات عربي احترافي بواجهة RTL كاملة، مع مصادقة حقيقية وقاعدة بيانات سحابية عبر **Supabase**. لكل مستخدم حساب مستقل ببريد إلكتروني وكلمة مرور، وملاحظات معزولة تمامًا عن بقية الحسابات باستخدام **Row Level Security (RLS)**.

**الموقع المباشر:** https://abdulfatailabeeb93-cmd.github.io/notes-app/

## التشغيل

يكفي فتح `index.html` في متصفح حديث، أو تشغيل خادم محلي بسيط (مُفضَّل):

```powershell
cd notes-app
python -m http.server 8765
```

ثم زيارة `http://localhost:8765/`.

## إعداد Supabase

1. أنشئ مشروعًا في [Supabase](https://supabase.com/).
2. من **SQL Editor** نفّذ محتوى الملف `supabase-schema.sql` كاملًا.
3. من **Project Settings → API** انسخ:
   - `Project URL`
   - المفتاح العام `anon` (أو `publishable` في واجهة API Keys الجديدة)
4. ضع القيمتين في `supabase-config.js`:

```js
window.SUPABASE_CONFIG = {
  url: 'https://YOUR-PROJECT.supabase.co',
  anonKey: 'YOUR_ANON_OR_PUBLISHABLE_KEY'
};
```

5. من **Authentication → Providers → Email**:
   - للتجربة السريعة: أوقف **Confirm email** ليتمكن المستخدم من الدخول مباشرة بعد التسجيل.
   - للإنتاج: أبقِ تأكيد البريد مفعّلًا، وسيظهر للمستخدم تنبيه لفتح رسالة التأكيد.

6. إذا كنت ستستخدم «نسيت كلمة المرور»، أضف رابط موقعك إلى **Authentication → URL Configuration → Redirect URLs**:
   - `http://localhost:8765/`
   - `https://abdulfatailabeeb93-cmd.github.io/notes-app/`

> **مهم:** المفتاح العام `anon` / `publishable` مصمم للاستخدام في المتصفح، لكنه لا يحمي البيانات وحده. الحماية الفعلية تأتي من سياسات RLS الموجودة في `supabase-schema.sql`. لا تضع مفتاح `service_role` في أي ملف من ملفات الواجهة أو في المستودع.

## المزايا

- تسجيل حساب جديد وتسجيل دخول عبر Supabase Auth ببريد إلكتروني وكلمة مرور.
- عزل كامل للبيانات: كل حساب يرى ملاحظاته فقط (RLS).
- إنشاء وتعديل وحذف الملاحظات، مع سلة محذوفات واستعادة وحذف نهائي.
- تثبيت الملاحظات وإضافتها إلى المفضلة.
- بحث فوري، وترتيب حسب آخر تعديل أو تاريخ الإنشاء أو العنوان.
- عرض شبكي أو قائمة.
- ألوان للملاحظات، وعدّاد كلمات، وتنبيه قبل إغلاق المحرر مع تغييرات غير محفوظة.
- مظهر فاتح/داكن/حسب النظام، وتصميم متجاوب للجوال.
- إعدادات الحساب: تحديث الاسم، تغيير كلمة المرور، تصدير الملاحظات بصيغة JSON، حذف كل الملاحظات، وحذف الحساب.
- استعادة كلمة المرور عبر البريد الإلكتروني.
- اختصارات لوحة المفاتيح (بحث سريع، ملاحظة جديدة، حفظ، إغلاق).

## بنية البيانات

### جدول `public.notes`

| العمود | النوع | الوصف |
| --- | --- | --- |
| `id` | `uuid` | المعرّف الأساسي |
| `user_id` | `uuid` | صاحب الملاحظة، مرتبط بـ `auth.users(id)` |
| `title` | `text` | العنوان |
| `content` | `text` | المحتوى |
| `color` | `text` | لون البطاقة |
| `pinned` | `boolean` | مثبتة |
| `favorite` | `boolean` | في المفضلة |
| `trashed` | `boolean` | في المهملات |
| `created_at` | `timestamptz` | تاريخ الإنشاء |
| `updated_at` | `timestamptz` | آخر تعديل (يتحدث تلقائيًا) |
| `deleted_at` | `timestamptz` | وقت النقل إلى المهملات |

### الحماية

- `RLS` مفعّل على `public.notes`.
- أربع سياسات منفصلة: `select`, `insert`, `update`, `delete`.
- جميعها تشترط `auth.uid() = user_id`.
- دور `anon` لا يملك أي صلاحية على الجدول.
- دور `authenticated` يملك الصلاحيات الأساسية فقط.
- حذف الحساب يتم عبر دالة `delete_my_account()` ذات `security definer`، وتحذف صف المستخدم الحالي فقط من `auth.users`؛ فتُحذف ملاحظاته تلقائيًا عبر `ON DELETE CASCADE`.

### التخزين المحلي

لم تعد الملاحظات أو الحسابات تُخزَّن في `localStorage`. يبقى في المتصفح فقط:

| المفتاح | المحتوى |
| --- | --- |
| `mulahazati.theme.v1` | تفضيل المظهر |
| `mulahazati.layout.v1` | تفضيل طريقة العرض |

جلسة Supabase يديرها `supabase-js` تلقائيًا، وتُحفظ بأمان وفق إعدادات المكتبة.

## الأمان والخصوصية

- كلمات المرور لا تمر عبر كود التطبيق ولا تُحفظ فيه؛ يتولاها Supabase Auth.
- النقل مشفّر عبر HTTPS.
- الوصول إلى الصفوف محكوم بـ RLS على مستوى قاعدة البيانات، وليس على مستوى الواجهة فقط.
- المفتاح العام `anon` لا يمنح وصولًا إلى بيانات مستخدم آخر عند تفعيل RLS بشكل صحيح.
- لا تشارك مفتاح `service_role` أو أي مفتاح سري في المستودع أو في المحادثات أو في ملفات الواجهة.
- الملاحظات غير مشفّرة من طرف العميل (client-side encryption)؛ من يملك وصولًا إلى حساب المستخدم يمكنه قراءتها. إن كنت تحتاج تشفيرًا من طرف العميل، فهذه ميزة إضافية منفصلة.

## الملفات

- `index.html` — بنية الواجهة العربية و RTL.
- `styles.css` — نظام التصميم، المظهران الفاتح والداكن، والتجاوب.
- `app.js` — المصادقة عبر Supabase، إدارة الملاحظات، الإعدادات، والتفاعلات.
- `supabase-config.js` — رابط المشروع والمفتاح العام فقط.
- `supabase-schema.sql` — الجدول، الفهارس، سياسات RLS، والصلاحيات ودالة حذف الحساب.
- `.nojekyll` — تعطيل Jekyll على GitHub Pages.
